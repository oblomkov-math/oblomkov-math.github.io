About the project

The goal of the project is to learn some interesting mathematics and to learn to realize your mathematical ideas in software. As the main vehicle for the software part of the project we use Sage, a Python-based mathematical library.

Another objective is to learn to work in a team. A large part of working in a team is communicating with each other and synchronizing your progress with the other members, and the standard tool for that is Git, which we will learn to use.

More broadly, our objective is to learn some standard tools and methods from the software development world. The link below collects resources that should help you set up your system and start learning the crucial pieces of software.

Mathematics

The mathematical part of the project centers on the combinatorics of three-dimensional partitions. Without going into specifics, the major goal is to find a purely combinatorial proof of the equality between the topological capped vertex written in the PT and DT presentations. You will learn about these objects later in the course of the summer.
